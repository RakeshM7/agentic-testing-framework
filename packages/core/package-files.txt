# What the published @testagentic/atf may contain (docs/packaging.md §2, §3.11): every file in packages/core/dist,
# by its path there with `/`. `node scripts/build-package.mjs` checks the build against it, and the release workflow
# runs the same check (`--check`) before it publishes.
#   - A plain path is required: the check fails when dist lacks it.
#   - A glob (`*` within one folder, `**` across folders, `?` one character) must match at least one file.
#   - A line starting with `!` is never allowed, even when a line above matches it.
# A dist file no line allows fails the check, as does a required one that is missing. Add a line here only for a file
# a client's install needs at run time: tests, fixtures, the decision log, feedback/ and the maintainer docs never ship.
