# Changelog

The extension is released together with `@testagentic/atf`, under the same version: use the extension whose version
matches the package installed in your workspace.

## 0.1.0

The first release.

- **Runs view:** each product's runs, their status and the next stage; start or continue a run, resume a stage, and
  refresh.
- **Clarifications view and editor:** the open clarification rows by product and module, edited in a sheet that writes
  through the framework's scripts.
- **Test case approval view and editor:** the cases awaiting sign-off by module, with the approval sheet. Approving a
  module runs in a terminal, where you type the confirmation yourself.
- **Report:** a run's report deck in an editor tab, locked to the report's folder, with no network access.
- **Workspace commands:** create a workspace, sync and check the host files, and the doctor, each in a terminal.
