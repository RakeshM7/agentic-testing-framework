Case study · Findings

What it found. What it taught us.

In the application

  • Account phone “abc” is accepted
  • Deal value of -5 is accepted, though the rules say reject
  • A deal marked Lost saves with no reason
  • Contact save is blocked with only a mobile number
  • GET /tasks with page=0 returns a 500

In the framework

  • Mutating API calls need an X-CSRF-Token or return 422
  • Parallel explorers shared one browser, so explore_concurrency is now 1
  • The guard hook blocked k6 because mode was not in the shell environment
  • Rate-limit cut-offs orphaned test data, so a scoped cleanup agent removed it
  • 11 feedback files filed for the implementor
