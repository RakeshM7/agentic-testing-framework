4

Four layers. The human supplies one run-config. The orchestrator invokes each spoke as a single request/response call; there is no long-running process. Every spoke reads and writes the shared artifact tree, so a run started by hand can be finished by the orchestrator and vice versa. models.yaml plus a sync script sets the model per agent for both flavors. The orchestrator cannot pause to ask a human mid-run, which is why the run-config pre-answers recurring questions.
