The problem

End-to-end testing is still manual and fragmented.

Discovery is manual

Testers click through the app by hand to learn what pages, flows and endpoints exist.

Rules stay implicit

Expected behaviour and edge cases live in people's heads, not where a test can trace to them.

Test assets drift apart

Manual cases, UI automation and API tests are written separately, so coverage diverges.

Unguarded agents are risky

An agent left alone on a live tenant can create, edit or delete real data.

2

Four pain points: manual discovery, implicit requirements, drifting test assets, and the risk of letting agents loose on live systems. The framework addresses all four together.
