Case study

Freshsales CRM. The whole product, one config.

Target

Freshworks CRM trial tenant, signed in as an organization admin

Mode

full-run, set by the tenant owner. Deletes limited to entities each track created

Scope

full-product, with four parallel tracks and one explorer at a time

One invocation

Use orchestrator-agent with configPath=config/run-config-full-product.example.yaml

It discovers modules by live navigation and vendor docs, then runs every stage for each module it selects.

8

The run was made against the user's own Freshworks CRM trial tenant, with full-run authorised explicitly in the run-config. Config used: run-config-full-product.example.yaml with explore_concurrency=1, max_parallel_tracks=4 and max_modules=20. Artifacts live in artifacts/rakesh-freshsales-ind-sep21.
