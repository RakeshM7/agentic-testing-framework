Folder structure

Agents on one side. Artifacts on the other.

PathWhat lives there
claude-agents/Seven personas, Claude Code flavor (.claude/agents)
copilot-agents/The same seven, GitHub Copilot flavor (.github/agents)
config/run-config YAMLs and models.yaml
scripts/Model sync, run-config validator, clarification CSV tools
docs/conventions.md: the shared artifact and feedback contract
artifacts/<target>/Per-target handoff: explore, clarifications, testcases, api
playwright-tests/Generated UI suite, functional and visual
api-tests/Playwright API specs and k6 scripts
feedback/<agent>/Dated feedback files, each with a Resolution appended

7

Four tiers with different lifetimes: the agent definitions are the product and change rarely; config holds one run-config per target; artifacts are per-engagement handoff data; playwright-tests and api-tests are standalone projects meant to be lifted into the repo that owns the product. Copying claude-agents/ or copilot-agents/ into another repo makes the framework available there.
