Safety model

Safe by default. Four guardrails.

1

One master switch

authorizations.mode is readonly by default. full-run is set per target by a human, never inferred.

2

Self-created scope

Deletes only touch entities this run created, logged in created-entities.json. Holds in both modes.

3

No inline secrets

Credentials come from a .env file. Only the file path is ever passed to an agent.

4

Human authorization

Full-run and authenticated crawls are opt-in fields. The orchestrator never escalates them.

6

In readonly mode no agent clicks a mutating control, API tests stay GET-only, mutating Playwright specs are generated but skipped, and k6 is never run live. In full-run mode, mutating specs execute and k6 may run, but destructive actions remain limited to entities the run itself created. Irreversible real-world side effects with no sandbox path are skipped regardless of mode.
