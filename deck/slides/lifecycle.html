2

3

Design

4

Automate

Playwright UI suite plus API tests and k6.

5

Learn

Feedback files are fixed and resolved.

Closed feedback loop

Agents file feedback and pass only the path. The implementor fixes it and appends a Resolution.

Resumable

Artifacts on disk are the checkpoint. Re-invoke after a halt and finished stages are skipped.

Halt, never guess

An unanswered blocking question stops the run and is reported by name.

5

Five stages. Stage 4 runs the Playwright UI agent and the API agent from the same test cases. Feedback is a closed loop kept outside the linear per-target pipeline. The orchestrator checks for each stage's output file before invoking a spoke, which makes re-invocation after a halt a resume rather than a restart.
